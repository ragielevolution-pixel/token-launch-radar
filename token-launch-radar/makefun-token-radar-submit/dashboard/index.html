How the ranking works

Implied value = TVL × peer multiple × growth × maturity × chain spread. The peer multiple is the median market-cap-to-TVL of live-token protocols in the same category (at least 3 peers, otherwise the global median), clamped to 0.10–4.00. Growth is the 7-day TVL change clamped to −40%…+80% and weighted 0.6. Maturity rises with the days since DefiLlama first listed the protocol. Chain spread rewards protocols live on more chains. Nothing is special-cased by name, and the value is this radar's own claim — it does not predict whether or when a token is issued.

“Records no token” means the sealed DefiLlama snapshot records no token for the protocol. It is not proof the protocol has none.
